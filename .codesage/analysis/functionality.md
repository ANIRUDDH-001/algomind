# Functionality Audit

## USP (Unique Selling Proposition)
Interactive, low-latency voice-driven technical interviews with multi-dimensional cognitive assessment and FSRS-based spaced repetition learning.

## Features
- ✅ Interactive Split-Pane Code Editor (Piston execution)
- ✅ Real-time Voice Interviewer (AWS Polly + Groq STT)
- ✅ RAG-based context retrieval (pgvector)
- ✅ 8-dimension cognitive skill assessment
- ✅ Dashboard and Cohort Analytics
