# AlgoMind Cognitive Skill Taxonomy

This document describes the 8 cognitive dimensions measured by the AlgoMind Assessment Engine.

| Skill | Weight | Description |
|-------|--------|-------------|
| **Problem Decomposition** | 15% | Breaking complex problems into manageable sub-tasks. |
| **Pattern Recognition** | 15% | Identifying algorithmic patterns and appropriate data structures. |
| **Algorithmic Thinking** | 15% | Designing efficient, logical steps to solve the problem. |
| **Complexity Analysis** | 12% | Reasoning about Time and Space complexity (Big O). |
| **Communication Clarity** | 12% | Articulating thoughts and logic clearly via voice. |
| **Edge Case Awareness** | 10% | Anticipating nulls, overflows, and boundary conditions. |
| **Optimization Mindset** | 11% | Seeking performance improvements beyond brute force. |
| **Debugging Approach** | 10% | Systematically isolating and correcting logic errors. |

## Scoring Rubric
Each skill is scored on a scale of 1-10:
- **1-2 (Poor)**: Fails to demonstrate basic competency.
- **3-4 (Below Average)**: Demonstrates basic awareness but lacks depth/accuracy.
- **5-6 (Average)**: Competent but requires prompting or has gaps.
- **7-8 (Good)**: Strong performance with minor areas for polish.
- **9-10 (Excellent)**: Exemplary performance; high-level mastery.
